Workflow & Decision Authority · Deterministic Architecture

Evidence checks and seller approval

A deterministic pipeline where models observe, code verifies, and the seller authorizes.

01 · INGEST Receive & Retrieve Buyer video & message via mock chat; queries order and courier APIs.
02 · OBSERVE Model Observation Models inspect frames and generate structured observations with timestamps.
03 · CHECK Policy Engine (Code) Pure code evaluates 7-day window, delivery date, SKU match, and refund cap.
04 · VERIFY Independent Critic Audits cited frames to confirm observations are supported by actual visual data.
05 · AUTHORIZE Seller Gate Seller 1-click approval permits mock return label & refund draft.
UNCLEAR EVIDENCE Asks for specific photo (e.g. tag/serial) and resumes the exact same case.
MISMATCH / CONTRADICTION Escalates directly to seller review with proof pack; never auto-denies.
ALL POLICY CHECKS PASS Prepares 1-click approval package for seller; draft in pending_return_receipt.
AUTHORITY MODEL: Server-enforced limits · Models observe; pure code evaluates policy · Seller approval required for all actions
