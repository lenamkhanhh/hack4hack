CALL BUDGET
Exactly 3 Model Calls

1. Planner proposes typed tool actions.
2. Vision model inspects server-generated keyframes.
3. Critic evaluates citations against policy. Model never accesses payment APIs directly.

STATEFUL RESUMPTION
Case C: Re-Film Loop

When video is too dark (brightness 28, 2 frames), agent calls ask_for_evidence() with a re-film checklist. Case state saved to WAITING_FOR_EVIDENCE and resumes on upload (1 retry limit).

SECONDARY ROUTE
Tiny PS-04 Order Route

For routine "Where is my order?" inquiries, agent bypasses vision entirely: Store API → Courier API → Instant status reply. Zero token waste.

FAIL-CLOSED FINANCIAL GATE: requires_seller_approval: true · Approval binds case + evidence hash + policy version.
Server Cap: 0 < amount <= min(₹4,999, remaining_refundable, order_paid) · Revalidation check before draft release.
