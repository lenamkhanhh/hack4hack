1. CONTRADICTION → ESCALATE
Discrepancy flagged (e.g. Case B). Inhibits automated label/refund. Seller reviews 3 options.
2. HARD FAIL → ESCALATE
Mandatory rule violation (e.g. expired return window). Seller makes final decision; never auto-deny.
3. UNCLEAR ONLY → ASK MORE
Low brightness or blurry barcode (e.g. Case C). Prompts exact re-film checklist (1 retry limit).
4. ALL PASS → APPROVE REVIEW
All clauses pass (e.g. Case A). Prepares mock label and drafts refund in pending_return_receipt.
